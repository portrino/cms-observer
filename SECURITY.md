# Security Policy

> [!CAUTION]
> **Please avoid using GitHub issues to report security vulnerabilities.**

If you have found a potential security flaw in the CMS Observer, please report it privately through
[GitHub's private vulnerability reporting](https://github.com/portrino/cms-observer/security/advisories/new).
We will look into it and get back to you there.

Vulnerabilities in a client belong to its own repository:
[TYPO3 client](https://github.com/portrino/cms-observer-client-typo3/security),
[WordPress client](https://github.com/portrino/cms-observer-client-wordpress/security).
